# NXTFRM data viz

One chart = one question. Generic chart and accessibility skills still apply; follow these product rules.

## Weight

- Morning weight is canonical. Post-workout weight is contextual and visually secondary.
- Keep recent trajectory separate from the long-term goal journey. A distant goal must not destroy recent Y-axis readability.
- Default chart: raw morning values plus a smoothed trend.
- Projection is visually distinct from trend: dashed or faded forecast.
- Show uncertainty only when a real model supports it. If confidence is weak, do not imply precision.

## Interaction

- The whole plot should be easy to scrub.
- The selected value updates a stable metric header.
- Critical interpretation is visible without interaction.
- No chart clutter. No unnecessary gradients.

## Performance

- Show comparable exposure history. Keep lift trends small and restrained.
- Do not claim muscle is preserved.
- Prefer Holding, Review, or declining-evidence language.

## Body

- Separate metric scales. Never cram weight, body-fat, muscle, and waist into one multi-scale chart.
- Compare checkpoints where that comparison is useful.

## Accessibility

- Do not rely on colour only. Distinguish series with point, line, and shape.
- Provide a textual summary. Charts need useful accessible labels.
